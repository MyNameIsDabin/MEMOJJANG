# メモチャン (메모짱)

昔ながらのドット文字で動く、ひとつの大きなキャンバスに **やること・メモ・リンク・画像** をどこにでも貼っておくデスクトップアプリ。

メモ帳では素っ気なく、Notion では大げさすぎるときのための場所です。
果てのないキャンバスに好きなところへぽんと放り、つまんで動かし、`Ctrl`+ホイールで拡大縮小しながら使います。

> **AI と一緒に作ったプロジェクトです。**
> コードもアイコンも、この文書までほとんどを Anthropic の Claude と一緒に書きました。
> 何を作るか、どう動くべきかは人が決め、実装と仕上げを AI が受け持つやり方で進めています。

![メモチャン — やること、マークダウンのメモ、リンク、画像ノートがひとつの板に並び、ステッカーで飾られた様子](docs/board.png)

## 手に入れる

**[→ 最新版をダウンロード](https://github.com/MyNameIsDabin/MEMOJJANG/releases/latest)**

Windows 10 / 11 (x64)。`Memojjang_x.y.z_x64-setup.exe` を落として実行してください。
`.msi` も一緒に上がるので、組織で配るときはそちらを使ってください。

署名していないアプリなので、初回は SmartScreen が一度止めます。
**詳細情報 → 実行** を押せば進めます。ソースはすべてここにあるので、自分でビルドしても同じものができます。

## ひととおり見る

### 文はそのかたちのまま見せます

メモの下の情報帯で見せ方を選びます。そのまま・マークダウン・コード・JSON・HTML。
JSON は読みやすく字下げされ、キー・文字列・数値・`true`/`false`/`null` が色で分かれます。
貼り付けた文を見て、勝手に決めさせることもできます。

マークダウンは**描いたまま直せます。** `#` や `**` といった印は隠れ、見出しは実際に大きくなります。
カーソルをそこに置けば印が戻ります — 見えないものは直せませんから。別の編集モードはありません。
コードブロックは囲い(` ``` `)ごと畳まれて一つの塊になり、中に入ると囲いが戻ります。

![JSON・HTML・マークダウンのメモがそれぞれの姿で描かれた画面](docs/views.png)

### 締め切りは目覚ましのように

やることの項目にマウスを載せると時計ボタンが出ます。**時・分・秒を入れて「始める」**を押せば、
そこから数えはじめます。単位をはみ出して書いても構いません — `90` 分は一時間半としてそのまま足されます。
日付まで決める締め切りは下の枠に直に書きます。どちらでも行の右側に `4日 残り` `20分 残り` のような
残り時間と進み具合の帯が付きます。左の取っ手をつまめば順番も入れ替えられます。

![やること項目の締め切りポップアップ — 時・分・秒を入れるタイマーと日付の枠](docs/due.png)

## 何ができるか

- **キャンバスを何枚でも** — キャンバス一枚がファイル一つです。好きな場所に作っておき、上のタブで行き来します。仕事用と私用を分けたり、案件ごとに一枚ずつ持ったりできます。
  タブ帯の右端の **`+`** を押すと、新しく作るか、フォルダーから探すか、**最近開いたもの**から選ぶかを尋ねます — 閉じたタブはここから戻せます。
- **無限キャンバス** — `Ctrl`+ホイールでカーソルを中心に拡大縮小、空きをつまむかホイールドラッグで移動。
  100%・200% のあたりでは少し吸い付いて、ドットがくっきり保たれます。
  **素のホイールは画面を動かしません** — 長いメモを送りきった拍子にキャンバスが釣られて動いたり倍率が跳ねたりしないよう、画面を動かすのは手でつまむ側だけに任せています。
- **ノートは四種類**
  - **やること** — Enter で次の項目、空の項目で Backspace なら消えます。左の取っ手をつまんで順番を変え、
    時計ボタンで締め切りを決めると残り時間と進み具合の帯が付きます。
  - **メモ** — ただ書く枠です。文字を貼るとこれになります。下の情報帯で **見せ方**
    (そのまま・マークダウン・コード・JSON・HTML) を選べますし、貼った文から勝手に決めさせることもできます。
    その判断のもとになる決まりは、設定で足したり外したりできます。
  - **リンク** — よく行く場所を自分の呼び名と一緒に集めます。サイトのアイコンが自動で付き、押すと既定のブラウザーで開きます。
    このノートだけを選んだまま住所を貼ると、新しいノートではなく **その一覧に直に入ります**
    (何行もあれば一度に何件も)。住所でない文はいつもどおりメモになります。
  - **画像** — 貼り付け (`Ctrl+V`)、ブラウザーから絵をつまんで落とす、右クリック → **画像を開く**、
    または **切り取って取り込む** で生まれます。大きさを変えても元の比を守るので、切れたり余ったりしません。
    下の `✎` を押すと **鉛筆で描き足せます** — 色と太さを選び、一筆ずつ消すことも全部消すこともできます。
    描き足したものは座標としてだけ残るので **元のファイルはそのまま** で、ノートを広げれば絵と一緒に大きくなります。
- **画像を貼る** — スクリーンショットを撮って `Ctrl+V` すれば、カーソルの位置にそのまま貼られます。絵は別のファイルとして保存され、ノートにはファイル名だけが残ります。
- **切り取って取り込む** — 右クリック → **切り取って取り込む**。画面がその瞬間で凍り、取り込みたいところを
  つまんで選ぶとすぐ画像ノートになります。ほかの切り取りアプリを挟む必要がありません。`Esc` でやめられます。
  画面が何台あっても一枚として覆い、ノートに入る切れ端は元から切り出すので画質は落ちません。
- **飾りつけ** — 上の道具帯のステッカーボタンを押すと飾りつけの状態になります。ノートが白黒に薄れて
  留められているのが一目で分かり、上に何をすればよいかが一行で出ます。
  空きを右クリックしてステッカーを選ぶとその場に貼られ、角の取っ手をつまんで **回して大きくします**
  (`Shift` なら大きさだけ、`Ctrl` なら5度ずつ)。
  左下の輪をノートへ引けばそのノートに **くっついて一緒に動き**、つなぎ目の線にマウスを載せると
  はさみになって押した瞬間に切れます。`Enter` で置き終わります。
  くっつけるときはノートの **四隅と真ん中** のどこかを選びます。そこが基準になり、
  ノートの大きさを変えるとステッカーがその角について行きます — 右下に吊るせば、いくら広げても右下のままです。
  下の道具帯で **位置** (ノートの後ろ・本文の下・ノートの前)、**透明度** (つまみか数字)、**白黒**、
  **かたち** (四角・丸・星) を選びます。「本文の下」はノートの内側に敷かれ、紙の模様のように見えます。
- **ステッカー包みのやりとり** — ステッカーの引き出しから選んだものだけを、ファイル一つに **書き出せます**。
  絵の中身までその中に入るので、受け取る人はファイル一つあれば足ります (`.mjsticker.json`)。
  **読み込み** で人の包みをそのまま引き出しに入れられます。
- **ノートを丸ごとコピー** — ノートを選んで `Ctrl+C`、貼りたい場所で `Ctrl+V`。
  中の文字ではなく **ノート一枚がそのまま** 複製され、くっついていたステッカーも一緒に行きます。
  別のキャンバスのタブに貼ってもよく、画像はそのキャンバスの `.assets` へ自動で移ります。
  画像ノートを一枚だけ選んだときは **画像そのものも一緒に** クリップボードへ載るので、
  ペイントやチャットにそのまま貼れます — 鉛筆で描き足したものも含めて。
- **画面いっぱいに開く** — ノートの題の帯にある `⛶` を押すと、そのノート一枚がキャンバスを丸ごと使います。
  窓の大きさを変えれば本文も伸び、`Esc` で元の場所に戻ります。ノートの位置と大きさはそのまま残ります。
- **探す** — `Ctrl+F` は題と本文をまとめて探します。下の帯の左にある `🔍` (`Ctrl+Space`) はノート一覧を開いて
  名前で選んで行く方で、探す枠は一覧の下に付いています。`↑` `↓` `Tab` で指して `Enter` で行きます。
  どちらでもノートを選べば画面の真ん中に来ますし、
  **画面いっぱいに開いて見ていたなら、その場所に選んだノートが代わりに載ります。**
- **新しい版** — 設定のいちばん上で新しい版が出たかを知らせ、押せば受け取って入れ直し、もう一度立ち上げます。
  受け取ったファイルは署名を確かめてからでないと入れません。
- **フォントを足す** — この機械に入っているフォントを名前で呼ぶことも、フォントファイルを直に読み込むこともできます。
  読み込んだファイルはアプリのデータ入れに写しておくので、元を動かしてもそのまま残ります。
- **整列と吸い付き** — 重なって絡んだ板を方眼に沿って並べ直したり、全部見えるように倍率を合わせたりします。
  吸い付きを入れると、ノートを置いた瞬間に **位置も大きさも** 方眼の点にぴたりと合い、つまんでいる間はどこに落ちるかが影で先に見えます。
- **ことば** — 한국어 · English · 日本語。設定のいちばん上で変えます。フォントがガルムリなので、
  今はガルムリが持っている文字に合うことばだけを載せています。辞書ファイルを一つ足せば言語を増やせます ([`src/i18n/`](src/i18n/))。
- **どこからでも呼び出す** — 既定は `Ctrl+Shift+Space`。どのプログラムからでも呼び出し、もう一度押すと隠れます。設定で好きな組み合わせを押して変えられます。
- **どこからでも画面キャプチャ** — 既定は `Shift+PrintScreen`。他のプログラムを使っている最中に押しても、**その画面がそのまま**写ります — メモチャンの窓は撮ったあとに出てきます。これも設定で変えられます。
  設定で **撮る前にメモチャンの窓を隠す** を入れると、メモチャンが少しのあいだ避けてくれます。既定は切 — 板ごと写したいときがあるからです。
- **昔ながらのドット文字** — 既定は [ガルムリ11](https://github.com/quiple/galmuri)。設定でガルムリ9 / 14 / Mono / システムフォントに変えられます。
- **テーマ三つ** — 夜 (既定) · 昼 · クラシック (あの頃の青緑の壁紙)。設定の **色を直す** で、キャンバスの下地、
  ノートの地、影、窓のふちといった色をひとつずつ変えられ (透明度が要る色はそれも)、いつでも既定に戻せます。
- **トレイに常駐 · 手前に固定** — 閉じてもトレイに残り、ほかの窓の上に留めておけます。
- **パソコンと一緒に起動** — 窓は出さずトレイにだけ入ります。**既定は切**で、設定から入れます。
- **クリップボードを集める** — 写すたびに板へ積んでいきます。私事に関わるので **既定では切ってあります**。

## ショートカット

| キー | すること |
| --- | --- |
| `Ctrl+Shift+Space` | **どこからでも** メモチャンを呼び出す / 隠す (変えられます) |
| `Shift+PrintScreen` | **どこからでも** 画面キャプチャを始める (変えられます) |
| `Ctrl+1` `Ctrl+2` `Ctrl+3` | やること · メモ · リンクを追加 |
| `Ctrl+V` | カーソルの位置に貼り付け (画像は画像ノートに) |
| `Ctrl+F` | 板の中を探す — もう一度押すと閉じます (探す窓での `Enter` も同じ) |
| `F2` | 選んだノートの名前を変える |
| `Ctrl+Enter` | 選んだノートを画面いっぱいに (もう一度で戻る) |
| `Esc` | 全画面のノートを戻す · 飾りつけを出る · パネルを閉じる · 選択を解く |
| `Ctrl+Space` | ノート一覧を開く — `↑` `↓` `Tab` で選び `Enter` |
| `Space` | 選んだノートを画面の真ん中へ (倍率はそのまま) |
| `Ctrl`+ホイール | カーソルを中心に拡大縮小 — ノートの上にカーソルがあっても効きます |
| ホイール | 中身があふれてスクロールが出たノートの上で、その中を送ります (`Shift` なら横に) |
| **ホイールドラッグ** | どこからでもキャンバスを移動 — ノートの上にカーソルがあっても効きます |
| 空きをドラッグ | キャンバスを移動 |
| `Shift`+ドラッグ | まとめて選択 |
| `Ctrl+C` | 選んだ **ノートを丸ごと** コピー (別のキャンバスにも貼れます) |
| `Ctrl+D` | 選んだノートを複製 |
| `Delete` | 選んだノートを削除 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す · やり直す |
| `Ctrl+0` | 拡大 100% |
| `Ctrl+Shift+0` | 全体が入るように |
| `Ctrl+Shift+G` | 方眼に沿って整列 |

ノートの題の帯はどこをつかんでもドラッグできます — ボタンの上でも同じで、動かさずに離せばそのボタンが押されます。
`✎` で名前を直し、`⛶` で画面いっぱいに開き、`▬` で畳み、左の小さな四角を押すと色が変わります。
帯を二度押すと畳まれます。

倍率と「手前に固定」は下の帯にあり、方眼の点のようにあまり触らないものは設定の中にあります。

窓の上側は OS の飾りを切ってアプリが自分で描いています。そうすることで題の帯・タブ・キャンバスが切れずに続きます。
アイコンも 16×16 の方眼の上に手で描いたものなので、ドットの感じが保たれます ([`src/ui/Icon.tsx`](src/ui/Icon.tsx))。

## 開発の支度

- **Node.js 20+**
- **Rust (stable, MSVC)** — <https://rustup.rs>
- **Windows**: Visual Studio Build Tools の「C++ によるデスクトップ開発」ワークロードと WebView2 ランタイム (Windows 11 には既に入っています)

```bash
npm install
npm run tauri dev      # アプリとして起動
npm run tauri build    # インストーラーを作る (target/release/bundle)
```

UI だけを触るときは、Rust のビルドを待つ必要はありません:

```bash
npm run dev            # http://localhost:1420 - ブラウザーで直に
```

ブラウザーではファイル保存の代わりに `localStorage` を使い、トレイ・手前に固定・クリップボード収集は動きません。

座標の決まりひとつを覚えれば、キャンバスのコードは読めます:

```
画面 = 世界 × zoom + viewport{x, y}
```

ノートはすべて世界座標に絶対配置され、`transform` は外側の包み一枚にだけかかります。
だからノートが何枚あっても、移動と拡大縮小の重さは変わりません。

## データの居場所

**キャンバスは自分で選んだ場所に** 保存されます。キャンバス一枚がファイル一つです。

```
わたしのボード.mjb.json      ノートと画面の位置
わたしのボード.mjb.assets/   貼った画像 (画像ができたときだけ作られます)
```

画像を本文に埋め込まないのは自動保存のためです。保存のたびにファイルを丸ごと書き直すので、
画像が数枚入るだけで毎回何 MB も書くことになります。その代わり **キャンバスファイルを動かすときは `.assets` も一緒に動かしてください。**

画像ノートを消しても、画像ファイルはその場では **消しません。** `Ctrl+Z` でノートが戻るとき、
画像も一緒に戻らなければならないからです。もう誰も指していない画像は、そのキャンバスを
**次に開くとき**にまとめて片づけられます。

アプリ自身の状態だけが `%APPDATA%\com.memojjang.app\` に残ります:

```
settings.json     フォント・テーマ・ショートカットなどの設定
workspace.json    どのキャンバスを開いていたか (経路の一覧)
```

この入れ物を消してもメモは飛びません — タブの一覧を失うだけで、キャンバスファイルをまた開けば戻ります。
設定の **キャンバスファイルの場所を開く** で、今のキャンバスがどこにあるかへすぐ行けます。

## サイトのアイコンについて

リンクノートのアイコンは、ファビコンの代行サービスを通さず **サイトから直に** 取ってきます。
どこをよく訪ねているかが第三者に漏れないようにするためです。
`/favicon.ico` と `/apple-touch-icon.png` を順に叩いてみて、どちらも無ければ文字のタイルで代わりにします。

そのため、アプリの CSP のうち `img-src` にだけ `https:` が開いています。画像は実行されないので
スクリプトを開くのとは危うさが違い、残り (`script-src`、`connect-src`) は閉じたままです。

## クリップボードを集めることについて

入れると、ほかのプログラムで写した中身まで板に積まれます。楽ですが、パスワード管理から写した合言葉のような
ものも一緒に残りうるので **既定では切ってあり**、集めた中身がこの機械の外へ出ることはありません。

Windows では `GetClipboardSequenceNumber` で変わったかどうかだけを見るので、見張りの費えはほぼありません。
ほかの OS では文字だけを集めます。
