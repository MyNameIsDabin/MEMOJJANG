### 이번 판에서 바뀐 것

**그림 노트를 `Ctrl+C` 하면 이제 그림만 복사됩니다.** 지난 판에서는 그림과 함께 노트 꾸러미도
올라가서, 글을 먼저 집는 프로그램에 붙이면 그림 대신 긴 글(JSON)이 나왔습니다. 이제는 어디에
붙여도 그림입니다. 연필로 덧그린 것은 그려진 그대로 나가고, 메모짱에 다시 붙이면 그림 노트로
들어옵니다. 여러 장을 고르거나 그림이 아닌 노트를 복사하면 지금까지처럼 노트가 통째로 갑니다.

**탭을 끌어서 차례를 바꿀 수 있습니다.** 탭을 옆으로 끌면 놓을 자리가 미리 보이고, 놓으면
그 차례가 저장되어 다시 켜도 그대로입니다.
